Controls

Drag map: pan · wheel: zoom
Drag a corner: move it (shared corners of neighbours move along; Alt at drag start moves only this one). Snaps to other corners/borders, else the grid.
Double-click a border: add a corner (on shared borders in both parcels) · right-click a corner: remove it
Structures: select, drag their points (lift stations, parking centre/direction, way points); double-click a way: add a point; right-click: remove
Esc cancel tool · Del delete selected parcel
